# 《奔奔王国 / Kingshot》核心机制研究

## 研究结论

《奔奔王国》不是单一的塔防或城建游戏，而是一个由三层循环套合的移动端 SLG：

1. **短时钩子**：剧情救援、居民加入、轻量守城，让玩家在数分钟内看到“废墟变家园”。
2. **中时经营**：资源生产、建筑升级、居民状态和兵种成长，把每次操作转成可见的城镇繁荣。
3. **长期元循环**：英雄收集、联盟协作、世界地图、研究与跨服竞争，持续制造升级目标。

证券行业报告将《奔奔王国》概括为“塔防开局 + 模拟经营过渡 + SLG”，并明确其为《Kingshot》的国内版本。官方介绍也同时强调居民经营、训练士兵、英雄、野外采集和防御入侵。

## 1. 前 15 分钟的转化漏斗

### 1.1 先交付变化，再解释系统

开场不是直接展示复杂的世界地图，而是让玩家护送或救出居民、清理据点、安排第一份工作，并经历一次低压力入侵。关键回报是：

- 空地上出现居民；
- 建筑从破损变为运转；
- 资源数字立即增长；
- 首次敌袭几乎必胜；
- 新系统只在已有行为之后解锁。

这使玩家先建立“我让这个地方活起来了”的所有感，再接触建筑等级、英雄和联盟。

### 1.2 一个操作同时推进多个指标

升级核心建筑不仅提高等级，还会解锁建筑、军队、居民容量与任务奖励。玩家感觉每一次点击都有多路回报。其核心不是复杂操作，而是把同一成长行为映射到多个可见结果。

### 1.3 用居民状态赋予生产线情感含义

居民不是纯数字工人。健康、幸福或满意度把食物、诊所、住宅等建筑与“照顾一群人”绑定。数值系统因此获得人物层面的反馈。

## 2. 核心循环

### 2.1 资源—建筑—人口循环

```text
采集与生产资源
  → 升级核心与功能建筑
  → 解锁更多居民、兵种和功能
  → 提高生产与防御效率
  → 进入更高成本的下一轮建设
```

核心建筑是进度门槛；训练建筑、研究建筑、仓库、医院和联盟设施围绕它形成依赖网。升级时间和资源缺口提供长期节奏，但也是其重付费化的主要来源。

### 2.2 居民—岗位—满意度循环

居民被分配到生产或服务岗位，产出食物、木材等资源。食物、住所和医疗反过来维持居民状态。状态下降会降低生产效率，从而形成柔性的失败螺旋。

### 2.3 防御—损耗—修复循环

守城战把经营成果转化为可见战斗力：防御设施、英雄与士兵抵御叛军；受伤单位进入治疗，城防需要修复，资源重新回流到经营层。

### 2.4 英雄—兵种—联盟循环

英雄提供战斗技能与编队差异，步兵、骑兵和弓兵形成长期培养线。联盟帮助缩短建设时间，并把个人发展转化为集结、领地和跨服竞争。

## 3. 真正值得保留的设计原则

我们不需要复制其完整 SLG，而应保留以下原则：

1. **城镇必须在玩家眼前发生物理变化**，不能只有菜单数字升级。
2. **获救居民要成为具体角色**，其职业和状态影响经营选择。
3. **经营和战斗必须互相消耗与回馈**，不能是两个无关小游戏。
4. **每 30–60 秒给一次小型可见回报**，每 2–3 分钟给一次结构性变化。
5. **首次失败应暴露一个可理解的短板**，例如缺医护、缺防线或缺食物，而不是只显示战力不足。

## 4. 不应复制的部分

- 不复制角色、建筑造型、世界观、UI 布局、文案、数值表或活动名称。
- 不采用数小时升级计时器、无限礼包入口、联盟强制和付费战力碾压。
- 不把广告里的塔防做成短暂诱饵；守城必须是主循环的一半。
- 不在首个版本做巨型世界地图和服务器战争；这些会稀释核心体验并显著增加后端成本。

## 5. 我们的原创转译

工作名：**《余光街区 / Afterlight District》**。

世界从中世纪改为被怪潮切断电力的现代街区。玩家维护最后一台街区发电机，白天搜索废墟、营救居民并按职业分工，夜里利用修好的路灯、防线和居民技能抵御怪物。三夜后点亮信标即完成一局。

原机制到新机制的映射：

| 原型原则 | 原创实现 |
|---|---|
| 核心建筑决定发展 | 发电机决定可用建筑槽和夜间照明范围 |
| 居民生产资源 | 居民职业与建筑匹配，形成食物、废料、电力产出 |
| 幸福/健康影响效率 | 士气与伤病影响工作和守城 |
| 叛军入侵 | 每日黄昏后出现不同构成的怪潮 |
| 英雄提供技能 | 关键职业居民提供一次主动技能，不使用抽卡英雄 |
| 长期 SLG | 8–12 分钟三昼夜单局，局外仅解锁新街区规则 |

## 6. 最小可玩验证问题

首个垂直切片只回答四个问题：

1. 把居民拖到合适岗位是否立即可理解且有满足感？
2. 白天资源选择是否会真实改变夜战结果？
3. 玩家能否从失败画面看懂自己缺少什么？
4. 三维街区在 390×844 与 320×568 上是否仍能看清角色、岗位和敌人路径？
