# Requirements

## 1. Overview

《余光街区 / Afterlight District》是一款手机竖屏三维生存经营守城游戏：玩家在三个昼夜内营救居民、按职业分配岗位、修复最后一块有电街区，并抵挡逐夜增强的怪潮。

玩家是希望获得 4–6 分钟完整策略体验的轻度玩家。情绪承诺是“亲手把黑暗废墟变成一小块温暖、有人生活的家”。核心操作是把具体居民分配到具体设施，并在三夜逐步增强的防守中持续使用电力与废料干预战局，而不是完成教学后只能观看。

## 2. Visual Design

游戏使用单屏竖向、正交等距的低多边形街区。上方约 16% 显示昼夜、士气和三种资源；中间约 62% 是玩家不可自由旋转、由剧情导演切换机位的街区主场景；下方约 22% 是居民队列、建筑操作和情境按钮。平台内画面按不存在访客栏设计。开场环境必须用连续高差地形和稀疏的大块构图，至少约 45% 区域不放置高物件，并在教学到来前隐藏发电机、工作台、路障和中继灯。主验收镜头不得看见地形外缘；发光窗户、发电机和中继灯除 emissive 表面外必须真实照亮附近模型与地面。

必需场景包括：首次进入、白天经营、居民待分配、黄昏预警、夜间战斗、高反馈救援或击退时刻、胜利、失败、资源不足、居民受伤与窄屏状态。角色、建筑、怪物和 UI 必须属于同一套硬边低多边形视觉语言；功能图标统一使用自绘线性 SVG，不使用 Emoji。

渲染必须按设备能力自动选择 low / balanced / high 三档，并在连续 8 秒实际帧率低于 42 FPS 时降一级。低档仍需保留轮廓抗锯齿，但可关闭 Bloom、把阴影降至 1024²、GTAO 降至 6 samples、DPR 限制为 1–1.25；高档使用 4× MSAA、SMAA、12 samples GTAO、2048² 阴影与 1.5–2 DPR。漫画勾边必须是选择性的：low 只勾当前目标，balanced 勾当前目标、人物与敌人，high 额外勾主信号屋；地面、道路、远景和普通设施永不勾边。

## 3. Game Mechanics

### 初始状态

- 单局包含 3 个白天节点和 3 个夜晚，目标时长 4–6 分钟；第三夜成功后才完成整局。
- 第一、二、三夜分别持续 32、36、40 秒；人物对白、升级选择和施工演出暂停防守计时。
- 发电机初始耐久 100，电力 40，废料 25，士气 60；初始路障耐久 60、上限 100。
- 剧情居民为值守员乔与工人林。第一日先救出林并分配到工作台，后续两日不重复新手教学。
- 当前切片开放信号屋、工作台、发电机、南路路障和两盏中继灯；食物、厨房、诊所和更多居民留待后续内容扩展，不在本轮 HUD 中伪装成已开放系统。

### 首次引导

- 首次体验依次只开放四个动作：点击搜救点、把工人拖到工作台、让林前往并修复路障、在敌人进入灯区后触发路灯过载。
- 工人正确落位后不得瞬移到岗位。状态先进入 2.8 秒的 `assigning` 演出：前 0.32 秒在镜头内的道路集合点原地转向，随后沿开放前景中的三段路径行走，最后 0.38 秒在工作台侧方转身站稳；只有到岗后才进入 `production-proof`、播放工作动作并结算首次 `+3` 废料。
- 行走进度使用逐帧增量时钟，单帧最多推进 100ms；60–10fps 设备保持约 2.8 秒节奏，低于 10fps 或线程长时间阻塞时允许演出延长，但禁止按绝对墙钟直接跳到终点。脚步声绑定 18% / 34% / 50% / 66% / 82% 路径进度，不使用可能先于人物到岗的固定延时。
- 每一步先由场内人物动作建立情境，再出现操作目标：受困工人在门口挥手、获救后指向工作台、值守员转身指向路障、敌人进入灯区时值守员发出过载口令。
- 搜救、分工和修复教学采用“场内演出 → 人物对白 → 目标定位 → 唯一操作”的注意力接力。场内演出约 650ms 后退出，才出现人物卡；玩家点击“查看目标”后人物卡必须收起，任务与目标先独立显示 900ms，最后才挂载按钮或居民卡。真正的步骤推进仍由玩家操作触发，自动间隔只承担表演交接，不能替玩家执行动作。
- 分配输入同帧确认岗位匹配并收起拖拽 UI；行走期间不增加文字面板，只保留人物步态、工作台勾边和镜头构图，也不提前展示资源奖励或生产对白。首次产出必须在角色到岗并开始工作后，只显示场内资源奖励，约 850ms 后奖励标签退出，再扩展资源托盘并显示下一步对白。黄昏先留出约 650ms 观察灯区，再出现守夜说明；夜战技能在乔发出口令后才开放。结算依次显示结果、统计和重玩按钮，不允许同帧一次性出现。
- 资源 HUD 按首次用途解锁：搜救阶段只显示电力；工作台目标出现后加入废料；进入夜战后加入士气。食物在厨房系统真正开放前不显示，禁止为了表现“系统完整”提前陈列无当前用途的数值。
- 每一步最多使用一组带角色立绘的对话和一句场内呼喊；不再用无人物归属的大段说明卡讲故事。对话只解释动机，目标环、镜头和人物动作负责解释操作。
- 镜头依次采用街区建立镜头、房屋救援中近景、工作台双人中景、路障道路中景、黄昏全景和夜袭跟随全景；玩家操作前镜头在 420–650 毫秒内完成移动。教学镜头必须同时容纳目标、指引角色和至少一段周边道路，禁止只看得到单个建筑局部。
- 错误操作不扣资源：错误拖放显示岗位效率并回弹；提前点击技能显示“等敌人进入灯区”。
- 开场可跳过，右上角帮助按钮可从当前步骤重播；本地记录已掌握步骤，正常回流不重复强制教学。
- 第一夜的前 8 秒为保护期，敌人造成的路障伤害降低 60%，确保玩家有机会完成主动技能教学。

### 路障施工演出

- 点击“修复路障”后立刻扣除 10 废料并进入 3.4 秒 `repairing` 阶段，不得同帧切到黄昏。
- 林从工作台岗位出发，前 0.30 秒转身，随后沿四点开放道路路径走到南路路障内侧，最后 0.85 秒停步并执行双臂施工动作；脚步绑定 22% / 39% / 56% / 73% 路径进度。
- 单帧施工进度最多推进 100ms；低帧率设备宁可延长演出，也不能从工作台瞬移到路障。
- 路障耐久只在林完成施工后恢复到 85；施工前不切黄昏、不生成敌人。林在此后黄昏和夜战中留在路障岗位，不瞬移回工作台。

### 昼夜推进与升级

- 每夜胜利后保留核心耐久、路障耐久和剩余资源；固定结算工作台产出 `+10` 废料、发电机恢复 `+10` 电力，数值上限均为 99。
- 第一、二夜结算按钮分别为“进入第二天”“进入第三天”，不得调用重新开始；只有第三夜胜利后显示“重新开始”。
- 第二、三天各选择一次准备方案：花费 8 废料“加固路障”，使路障上限永久 `+20` 并恢复 30；或花费 8 废料“扩充电池”，立即获得 22 电力。选择后才进入黄昏。
- 每夜敌潮压力系数分别为 2.35、3.20、4.15；后两夜要求玩家循环使用技能，不能仅靠初始路障被动通关。

### 黄昏决策

- 黄昏阶段暂停计时，显示当夜编号、剩余核心/路障和乔的短口令；玩家确认后进入防守。
- 第一夜承担技能教学，第二、三夜直接进入已掌握的双技能战斗界面，不重复人物长对白。

### 夜间防御

- 敌人沿两条可读路径走向发电机；路障阻挡路径，岗哨和守卫自动攻击。
- 第一、二、三夜分别显示 8、12、16 个敌人；快速敌人的占比逐夜提高，模型动作与移动速度保持物种差异。
- 敌人进入路灯区后，路灯过载消耗 6 电力，持续 6 秒，使压力降为 38%；技能从第 5 秒开放，每次使用后 11 秒可再次触发，资源不足或冷却中必须显示具体原因。
- 现场抢修从第 3 秒开放，消耗 4 废料，立刻恢复 14 路障耐久但不超过上限；每次使用后 8 秒可再次触发。按钮、路障浮动 `+14` 和林的施工动作在同一输入帧开始。
- 两个技能在整夜始终保留位置；不可用时显示冷却秒数、资源不足或“路障已满”，不得在第一次使用后永久消失或只剩禁用态。
- 路障耐久归零后，压力继续以每秒 7.5×当夜难度系数伤害核心；核心归零立即失败。
- 夜晚结束时士气恢复 8；路障与核心不自动回满，必须通过白天升级或夜战抢修管理。

### 反馈与特效

- 职业匹配时岗位轮廓在 160 毫秒内亮起，居民落位产生 6 个持续 420 毫秒的方形粒子。
- 搜救完成冻结计时 180 毫秒，镜头向救援点推进 4%，随后在 500 毫秒内回位。
- 敌人首次突破路障时提供不超过 3 像素、180 毫秒的相机震动；同一夜最多触发 3 次。
- 资源变化显示带来源的浮动数字，持续 700 毫秒；同类变化在 500 毫秒内合并。

## 4. Controls

- 点击废墟或搜救标记开始搜救；再次点击不重复提交。
- 居民卡使用 Pointer 拖拽到建筑岗位；进入有效岗位 24 像素范围时预览匹配效率，释放后分配。
- 点击已分配居民可打开 44×44 像素以上的岗位操作面板，并可撤回队列。
- 建筑、资源点和战术按钮使用 `onClick`；居民横向队列允许滚动，滑动不能触发选中。
- 夜战两个主动技能使用并排的至少 56px 高按钮，按下立即给出视觉反馈；技能冷却期间显示数字和文字，不依赖颜色单独表达。
- 键盘调试支持数字键 1–3 选择居民、方向键切换岗位、空格确认；正式移动端不依赖键盘或 hover。

## 5. Win / Lose Conditions

- 挺过第三夜且发电机耐久大于 0 时胜利；胜利画面显示发电机剩余耐久、路障耐久、最终士气与三灯完成徽记。
- 发电机耐久降至 0 或士气降至 0 时立即失败。
- 失败画面必须指出一个主要原因：防线破损、食物短缺、岗位错配或伤员未治疗，并提供对应的下一局建议。
- 第一、二夜胜利只允许继续下一天；失败时“调整后重试”重试当前夜并提供最低防守资源，不清除已经到达的天数。第三夜胜利后的重新开始才重置整局；本地保留已掌握教学标记。

## 6. Sound Effects

- 分配居民：木质短击与柔和确认音，320–520 Hz，90 毫秒，音量 0.28。
- 职业完美匹配：双音上行提示，440 Hz 到 660 Hz，160 毫秒，音量 0.30。
- 资源产出：低音量颗粒点击，180–260 Hz，60 毫秒；500 毫秒内同类产出只播放一次。
- 搜救成功：三音上行，392/523/659 Hz，总时长 420 毫秒，音量 0.38。
- 黄昏预警：低频脉冲两次，90–120 Hz，总时长 800 毫秒，音量 0.42。
- 岗哨攻击：短促噪声加 140 Hz 冲击，70 毫秒，音量 0.18；每 120 毫秒最多一次。
- 路障破坏：带衰减的木石断裂噪声，240 毫秒，音量 0.46。
- 发电机受击：80 Hz 正弦下滑至 45 Hz，180 毫秒，音量 0.50。
- 胜利：温暖四音和弦，持续 1.4 秒，音量 0.45；失败：两音下行，持续 900 毫秒，音量 0.40。
- 所有声音可单独静音；系统开启减少动态效果时不改变必要的音频提示含义。
