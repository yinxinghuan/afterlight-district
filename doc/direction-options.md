# 视觉方向候选

三个方向都使用共享低多边形模型语言与正交等距镜头，但在时间、构图、材质和 UI 隐喻上有实质差异。

## A. 停电后的最后一盏灯（推荐）

- **概念**：整个街区处于蓝黑停电状态，玩家修复的设施依次亮起暖白灯，生存进度直接表现为“光的面积”。
- **构图**：发电机位于画面中心偏下，两条敌人路径从左右上方黑暗处汇入；居民工作的建筑环绕发电机形成可读半圆。
- **相机**：42° 正交等距，镜头固定，只在救援与路障破裂时做 4% 以内推拉。
- **材质与光**：保留硬边 StandardMaterial；环境使用冷蓝月光，功能设施使用奶油白与琥珀灯，青绿色只表示电力链路。
- **调色板**：Blackout `#111821`，Night Slate `#26323D`，Warm Window `#FFD58A`，Power Teal `#3FB6AC`，Danger Coral `#D85B4B`，Paper `#F4EFE4`。
- **字体**：标题使用窄体粗黑无衬线；UI 使用系统无衬线与 `PingFang SC`；资源数字使用等宽数字。
- **UI**：像应急配电面板，深色扁平底板、细电路线、方角切口；资源不足表现为断开的线路，而非红色弹窗。
- **动效**：建筑通电沿线路逐段点亮；敌人进入灯区时由剪影变为三值受光模型。
- **记忆点**：第三夜结束，整块街区从中心向外逐盏亮起。
- **主要风险**：窄屏夜景容易丢失模型轮廓，需要严格控制暗部值差和 HUD 对比度。

## B. 灾后救援桌面沙盘

- **概念**：游戏像一个由应急指挥员操作的实体城市沙盘，居民和怪物都是可移动模型棋子。
- **构图**：道路地块铺在米白色桌面上，建筑槽带编号，资源与居民卡像压在桌面的纸质调度单。
- **相机**：更高的 52° 正交俯角，完整展示路径与岗位关系，牺牲部分角色表情换取策略可读性。
- **材质与光**：日间暖灰工作灯，模型保持平涂硬边，场景边缘露出沙盘木框和铆钉。
- **调色板**：Map Paper `#E8E0CF`，Graphite `#303433`，Safety Amber `#E2A63B`，Command Teal `#3FB6AC`，Alarm Red `#BE4C3C`，Ink `#171A19`。
- **字体**：标题为粗窄工业字；正文像清晰的救援表单，不使用手写体。
- **UI**：居民卡是带职业色条的调度标签；拖拽时出现路线箭头和岗位编号。
- **动效**：建筑落位像磁吸棋子，资源结算像盖章，夜战路径显示简洁方向线。
- **记忆点**：失败时沙盘上的对应短板被红色检查框圈出，直接解释败因。
- **主要风险**：情绪更理性，可能弱化“黑暗中点灯”的温暖承诺。

## C. 屋顶信号链

- **概念**：洪水或怪雾吞没街道，玩家沿相邻屋顶建立发电与灯光中继，最终把求救信号送到远方。
- **构图**：三至五个高低错落的屋顶形成纵向路径；每个屋顶是一组小型岗位，敌人沿天桥和梯子推进。
- **相机**：38° 正交等距，场景沿屏幕纵轴向上延伸，终点信标位于上方视觉焦点。
- **材质与光**：雾蓝背景、暖色屋顶灯、少量湿润反射，但不使用玻璃拟态或大面积发光描边。
- **调色板**：Fog `#AEBEC0`，Deep Water `#29454D`，Roof Clay `#9A614A`，Beacon Gold `#F0C45A`，Relay Teal `#3FB6AC`，Storm `#273138`。
- **字体**：较轻的几何无衬线标题；HUD 使用高对比小型标签。
- **UI**：资源与电力通过跨屋顶的实体电缆表达，面板减少，更多信息直接贴近世界对象。
- **动效**：电流沿电缆传播，屋顶之间点亮，浓雾随供电范围退开。
- **记忆点**：最终信号束穿透雾层，远处逐个亮起回应灯。
- **主要风险**：现有库存缺少屋顶、天桥、电缆和高层建筑，需要最多的新资产生产。

## 推荐

优先选择 **A**。它最充分利用现有路灯、房屋、居民与怪物模型，同时把“经营成果”转成极直观的亮灯面积；它与《Kingshot》的中世纪暖色城堡视觉也保持最大距离。
